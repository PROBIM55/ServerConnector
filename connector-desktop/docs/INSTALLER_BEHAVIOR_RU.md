# Установка Structura Connector

Пользователь запускает один `Structura.Connector.Installer.exe`. По умолчанию он устанавливает:

- NetBird из проверенного официального MSI. Более новая установленная версия сохраняется.
- Microsoft Edge WebView2 Runtime из полного установщика Microsoft, если рабочего Runtime ещё нет.
- Защищённые системные файлы коннектора и параметры сервера.
- Приложение в профиль исходного пользователя Windows, с ярлыками. .NET и библиотеки Visual C++ входят в пакет приложения.
- Встроенный Git, gltfpack и движок IFC. Отдельная установка этих инструментов пользователем не требуется.

Токен, доступность сервера и регистрация устройства не являются условиями установки. Для системных компонентов Windows может запросить UAC; приложение устанавливается без повышения прав в исходный профиль пользователя. Коннектор должен быть закрыт перед обновлением.

Подключение к аккаунту выполняется после установки в самом приложении. Разделы остаются зависимыми от выданных сервером прав. Установщик не создаёт учётные данные, не меняет старые подключения и не удаляет прежние приложения.

Blender не входит в EXE и не устанавливается в фоне. Пользователь запускает его загрузку и установку кнопкой в разделе АГР коннектора.

Сборка выполняется на изолированном Windows runner в GitHub Actions, под ограничением памяти всей группы процессов. Облачная проверка запускает настоящий установленный EXE под обычными пользователями Windows: чистая установка, обновление старого приложения, повторный запуск установщика и загрузка настоящего интерфейса WebView2. Исходящий трафик установщика блокируется на время проверки. Артефакт допускается к выдаче только после подтверждения установки без токена и отсутствия Blender.

WebView2 устанавливается по официальной схеме Microsoft: https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution.
