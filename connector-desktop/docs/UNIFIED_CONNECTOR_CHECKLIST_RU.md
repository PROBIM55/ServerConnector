## Как выполняем

1. Первый пакет ядра принят: управляемая пауза серверного исполнения.
2. Следующий результат: общий контекст заданий / каталог модулей, Agent и первый реальный
   экран новой оболочки. Дизайн заново не пересогласовываем.

   Конвертеры и админка подключаются по тем же контрактам.
4. Каждый пакет заканчивается адресными проверками и независимым ревью.
   Галочки обновляются после приёмки, существенные ограничения пишутся здесь.

Исследование расширяем только для конкретного технического решения или
неподтверждённого сценария. Главный ориентир — работающие функции приложения.
